# Reference glyph source

The glyph contours in `glyphs/` were extracted from the official Bravura SVG font, the reference font for SMuFL. Bravura is distributed under the SIL Open Font License 1.1.

The generated files retain the original glyph outlines. Canonical semantic names and MusicXML mappings are currently supplied for the common notation symbols used by the PoC; the remaining glyphs are retained as `smufl-unknown` references and can still be matched geometrically.
