# Real clef candidates

Exact post-sanity-filter candidates exported by the SvgStructure clef diagnostics from the three step-by-step scores. These are test inputs, not training references and not assumed to all be clefs: false positives are intentionally retained so the recognizer can be diagnosed against real pipeline traffic.

Subfolders preserve the source score and contain the original `.svg`, preview `.png`, and SvgStructure context `.txt` files.
